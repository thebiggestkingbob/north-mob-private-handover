# Handing this package to Codex
1. Unzip locally and read `01-MASTER-PROMPT/NORTH-MOB-MASTER-PROMPT.md`.
2. Attach the package to the Codex workspace, or place its files on a new repository branch. Codex cannot automatically read attachments from a separate ChatGPT conversation.
3. Avoid committing the 30 MB Mustard reference recording or other large video files to normal Git history. Keep third-party reference media private. Host first-party videos via suitable video hosting/storage or Git LFS.
4. Make `03-MOB-TIES-ASSETS/optimized-webp` accessible to the project; preserve originals outside optimized public media.
5. In Codex, paste the master prompt and ask it to audit first, confirm it can read the package, identify missing files/credentials, and return an asset map.
6. Approve the plan and visual preview before allowing implementation. Approve staging and full tests before production.
7. This package does not itself update the repository or send a message to your Codex chat.
